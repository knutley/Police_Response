**Event Codes:** GDELT relies on machine readable formats of CAMEO's (Conflict and Mediation Event Observations) Event Data Codebook. The information for these separate event codes is available here: https://github.com/tenthe/CAMEO-Event-Data-Codebook/blob/master/cameo.csv

**Codebook:** http://data.gdeltproject.org/documentation/GDELT-Event_Codebook-V2.0.pdf
Further explanation: http://data.gdeltproject.org/documentation/CAMEO.Manual.1.1b3.pdf

**Actor Codes:** Actor1 acts on Actor2, so there seems to be some sort of temporal chain of events included (which is good).
